# 选题和草稿

材料来源与 `/cheat-trends` 相同：用户给的话题、`big-v.md`、本地每日摘要。不要上网搜索，不要编新闻。

## 草稿

写到 `scripts/<YYYY-MM-DD>_<id>_<short>.md`。正文必须包含材料里原有的来源 URL。可以是：

- 单帖：一句到几句判断，加来源链接
- 回复：写明要回复的数字帖子 id，正文不编造对方没说过的话
- 引用转发：写明被引用帖的 URL，加上自己的判断

判断必须能指回材料里的句子或数字。材料不够支撑判断，就不要写这篇。

## 没有可写的

输出且只输出：

```
今天没有
```

前 5 篇还没发完时，也不要用「分可能不高」作为不写的理由。不写只因为没有带来源的材料。
