# 状态

读 `.cheat-state.json`、`predictions/` 和 `posts/`。不要发网络请求。

报告：

- 已发布篇数。小于 5 时写明：目前只收集数据，不按分数决定发不发
- 已到发布后第 3 天、还没有复盘的预测
- 最近几次有效复盘的方向（偏高、偏低或不可用）。不要把「不可用」或提前复盘算进连续三次
- 对标样本数。少于 5 时写「定性参考」，精度说明仍是大约 ±50% 的工作假设
- 钩子文件是否在 `.cheat-hooks/`。在的话也写上：宿主是否拦截未验证

连续三次同一方向时，可以写「可以考虑提议改评分，由你决定」。不要写「建议把校准池发给外部模型」。外部审核默认关闭。

不要提示安装抖音、小红书、视频号、LinkedIn 或 Whisper。
