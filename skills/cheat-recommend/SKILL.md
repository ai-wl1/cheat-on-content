# 推荐

只读 `candidates.md` 和用户当天给的材料。不抓取新热点。

候选必须已有来源链接。没有合格候选时，输出：

```
今天没有
```

有合格候选时，说明类型（单帖、回复或引用转发）、用了哪条来源、以及不适用的评分维度。前 5 篇不要把分数高低说成发或不发的理由。第 6 篇起可以对照已有复盘，仍然让用户决定。
