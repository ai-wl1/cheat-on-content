# 今日材料

不抓热点。不要 WebFetch，不要读 `adapters/trend-sources/` 去请求网站，不要运行 legacy 适配器。

## 输入

只使用这三类，而且都要用户已经放在本地或贴在对话里：

1. 用户这次给的话题
2. `big-v.md` 里的账号名单
3. 每日摘要文件，默认 `digest/` 下用户指定的那一份。这是另一个模块写好的文件，这里只读取，不生成网络请求

摘要里的链接和数字只能原样引用。文件里没有的链接不要补。

## 输出

有至少一条带来源链接、值得写成单帖、回复或引用转发的材料：写成 `candidates.md` 的一条，保留原链接。

没有任何一条满足：不要写候选，不要编一条新闻。整个回复就是：

```
今天没有
```

不要在这句后面加解释。
