# 复盘

只追加 `## 复盘`。不要改 `## 预测`，也不要重写已有复盘里的原话；要补充就再加一小节。

## 时间

默认采集日是发布日后的第 3 天。还没到就告诉用户还差几天。用户坚持提前记，可以追加，但必须写「提前复盘」，并且这次不计入连续三次同方向偏差，也不进入 `tools/score-curve.py`。

## 数据

请用户打开帖子的公开页面，粘贴看得到的：

- 浏览
- 点赞
- 回复
- 转发
- 书签（可选）。要写这是「公开页面可见」还是「公开页面不可见」

看不到的写「不可用」。不要写成 0，除非页面上就是 0。不要要求后台数据，不要登录，不要运行 `adapters/` 或 `legacy/` 里的脚本。

公开回复只记录用户粘贴的原句。没有就写「不可用」。

格式用 `templates/retro.template.md`。同时把同一份数字写入 `posts/<id>/report.md`，标明 `数据来源: manual paste` 和 `采集窗口: 发布后第 3 天`。

## 偏差

浏览是整数且不是提前复盘时，比较预测里的「中枢 ~ N」：

- 大于中枢：偏高
- 小于中枢：偏低

最近三次计入的复盘都是偏高，或都是偏低，才用文字提议改评分规则。提议停在对话和 `rubric-memo.md` 的建议段。不要自动修改 `rubric_notes.md`。

前 5 篇复盘只记录，不据此建议以后发不发。
